## About me

I'm a Senior Data & AI Engineer with **4+ years of experience** designing and building data platforms end to end — from ingestion and modelling to governance, CI/CD and AI-powered applications. I work across **Google Cloud**, **Azure** and **Databricks**, and I'm focused on what I call *AI Data Engineering*: bringing agentic AI systems into the data engineering lifecycle as a core part of how pipelines are specified, built and operated.

- 🏗️ **Lakehouse & Data Warehouse architecture** — Medallion (Bronze → Silver → Gold) on Databricks and BigQuery, terabyte-scale workloads.
- 🛡️ **Data governance & quality** — Unity Catalog, Dataplex, Policy Tags, lineage and data quality gates with quarantine of rejected records.
- 🤖 **Agentic AI for data engineering** — Claude Code workflows integrated via MCP (Model Context Protocol) with Databricks, Jira and SharePoint; reusable agent skills; LLM agents with ADK, LangChain and LangGraph; RAG.
- 🔁 **DataOps** — CI/CD with Azure DevOps and Cloud Build, isolated DEV / HML / PROD deployments, orchestration with Airflow (Cloud Composer).
- 📈 **Machine Learning** — Vertex AI and BigQuery ML, feature engineering, training, evaluation and deployment.

I'm currently living in Sydney, improving my English and preparing for a Master by Research, while staying hands-on with data and AI projects. I'm open to Data / AI Engineering opportunities in Sydney (on-site, hybrid or remote).
